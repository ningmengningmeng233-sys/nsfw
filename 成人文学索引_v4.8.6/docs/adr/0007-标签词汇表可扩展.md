# ADR-0007: 标签词汇表支持用户自定义扩展，skill 保持中文优先

## 背景

`templates/包含元素标签词汇表.md` 是小说索引技能中标签体系的单一来源，内容详尽但硬编码。用户若想加入新的标签组（如“克苏鲁”“规则怪谈”“赛博朋克”），只能直接修改 skill 文件，升级时容易被覆盖。同时，当前 `README.md` 仅是指向中文文档的简短说明。

## 决策

1. **标签词汇表支持自定义扩展**：默认内置表继续由 `templates/包含元素标签词汇表.md` 提供；用户可在索引库根目录放置 `tags.custom.yaml`，系统在加载时合并内置表与自定义表，冲突以自定义表为准。
2. **不做完整英文国际化**：skill 面向中文网络小说场景，README、模板、脚本输出均保持中文优先。`README.md` 仍作为简短入口，不单独维护完整英文版。

## 理由

1. **标签可扩展是真实痛点**：不同小说流派、个人创作习惯需要的标签差异很大，硬编码无法满足。
2. **自定义文件避免升级覆盖**：把用户扩展放在索引库而非 skill 目录，升级 skill 时不会丢失。
3. **中文优先符合目标用户**：该 skill 的核心场景是中文网文索引与创作辅助，强行双语维护会增加同步成本，收益有限。

## 备选方案

- **直接修改内置标签词汇表**：被否，因为升级会被覆盖。
- **完整翻译成英文并维护双语**：被否，因为目标用户主要是中文创作者，维护双语文档的成本高于收益。

## 后果

- 需要实现标签加载函数，支持多源合并与冲突规则。
- 需要在 README_CN.md 和 `references/索引内容.md` 中说明 `tags.custom.yaml` 的格式与加载位置。
- 如果未来出现非中文用户需求，可再单独讨论国际化，当前决策不关闭该可能性。
