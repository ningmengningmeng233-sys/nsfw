# 风格卡 v2：借鉴 image2-styles 定性骨架（方法论移植，素材不并入）

轻量蒸馏的"定性太弱"根因是脚本卡只是素材拼贴：语言指纹=金句摘录、没有一句话定性、
没有可粘贴的组合公式。waterblower image2-styles 系列（luminous-xianxia 等）的画风技能
有一套成熟的定性骨架——一句话宏观定性 + 可迁移指纹 + 量化表面语言（键值对）+
生成公式 + 禁则清单 + router 按需路由。

决定：把这套**骨架**移植到文风蒸馏（风格卡 v2 九节：①一句话定性 ②量化语言指纹
③~⑥叙事模型/母题意象/人物塑造/情节技法 ⑦组合公式 ⑧不可写 ⑨诚实边界），其中
"量化表面语言"由脚本直接对原文抽样统计（预算 min(500, 被抽段总行数×5%)），不依赖
LLM。**素材层不并入**：image2-styles 的 11 个画风技能是图像生成域，作为独立技能安装
到 `.agents\skills\`，与小说索引互不拷贝内容——内容合并会污染"仿XX文风"触发并拖大
技能体积。

被放弃的备选：①给脚本加 LLM 综合步骤直接产出最终卡——保留为后续选项，但脚本卡
定位是"素材底稿 + 实测指标"，定性判断留给编排器更符合现有单源真相分工；
②把画风技能的内容摘要并入小说索引做跨域风格卡——域错配，画风指纹（笔触/材质/光影）
对文字创作不可执行。
