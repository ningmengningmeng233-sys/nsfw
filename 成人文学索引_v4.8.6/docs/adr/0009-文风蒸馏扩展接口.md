# ADR-0009: 完整文风蒸馏预留扩展接口，当前不内建降级方案

## 背景

小说索引 v4.6 支持轻量文风蒸馏（由本 skill 自身完成）和完整文风蒸馏（依赖外部 `wenfeng-skill`）。完整蒸馏能力是创作辅助场景的高阶需求，但将其实现完全内建会显著增加 skill 体积和复杂度；完全依赖外部 skill 又会在未安装时失败。

## 决策

1. 在小说索引 skill 中**预留一个扩展接口**（如配置项 `INDEX_STYLE_SKILL` 或编排器中的 `style_distillation_hook`），用于指定接管完整文风蒸馏的外部 skill 或内部模块。
2. 当前**不内建完整蒸馏降级方案**，因为外部 `wenfeng-skill` 正在同步优化，提前内建会造成重复工作和接口不一致。
3. 当未配置扩展接口且外部 skill 不可用时，向用户明确提示：“完整文风蒸馏需要安装并配置 `wenfeng-skill`（或兼容接口），当前仅提供轻量风格卡。”

## 理由

1. **避免重复建设**：外部 skill 已在优化，等待其稳定后再决定是继续复用还是内建。
2. **保持接口干净**：预留 hook 后，未来无论是复用 wenfeng-skill、接入其他风格 skill，还是内建模块，都不需要改动小说索引核心流程。
3. **当前行为可解释**：用户清楚知道轻量/完整两种模式的边界和依赖。

## 备选方案

- **立即内建完整蒸馏模板**：被否，因为会与正在优化的外部 skill 产生功能重叠，且质量难以保证。
- **完全移除完整蒸馏概念，只做轻量**：被否，因为完整蒸馏是明确的高阶需求，不应因暂时不实现而放弃描述。

## 后果

- 需要在 SKILL.md 和示例文档中明确说明完整蒸馏的依赖条件。
- 编排器实现时要把 `style_distillation_hook` 作为配置点暴露。
- 未来 wenfeng-skill 稳定后，再评估是否需要基于该接口做一个内置降级模块。
