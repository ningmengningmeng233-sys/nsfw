# 更名「成人文学索引」并明确命名边界

技能实际使用场景全部是成人向小说（标签词汇表的"药物/迷奸系""调教/驯化系""洗脑/恶堕系"
等组、库内全部藏书均为成人文学），原名「小说索引」过于宽泛。决定：技能身份更名为
「成人文学索引」，v4.8.0 起 frontmatter `name`、标题、文档标题、编排器显示名同步更新；
触发词保留「小说索引」作为通用别名，防旧习惯失效。

**命名边界（防误改）**：索引库数据格式中的 `小说索引/` 目录（导航索引文件层）、
`templates/小说索引模板.md`、脚本中 "novel index/小说索引" 的数据格式语义**一律不改**——
它们是数据结构的名字，不是技能的自称；改名会破坏脚本硬编码路径（orchestrate.py 的
DIRS、index_db、build_novel_index.py）与现有 81 段索引的兼容性。技能自身机制
（拆段/索引/检索/蒸馏）保持内容中立，未写死成人向。

被放弃的备选：①连带把数据目录改名为 `成人文学索引/`——纯成本无收益，所有脚本与
既有库全断；②不改名、只在 description 加"成人"触发词——身份与实际用途长期错位，
用户检索与展示时仍会误导。
