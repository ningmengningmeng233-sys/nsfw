# 直调引擎作为默认建索引执行器

建索引存在两条可行路径：编排器派发子代理逐段分析（原案），或脚本直调 LLM API 并行生成。决定默认采用直调引擎（`scripts/build_segment_index.py`），子代理派发保留为可选路径（`.env` 的 `INDEX_EXECUTOR` 切换）。

## Considered Options

- **子代理派发（原案）**：被拒——每个子代理都要重新加载流程规范与模板，token 消耗高、实测单段 126 秒、占用编排器上下文。
- **纯直调**：被拒——直调依赖 `.env` 的 API 配置，无 API 环境或需人工判断的场景仍需子代理路径兜底。
- **双执行器并存（选定）**：直调引擎为默认，`.env` 的 `INDEX_EXECUTOR=subagent` 一键切回子代理派发。

## Consequences

- 实测直调单段 70 秒（vs 子代理 126 秒），500 章全书索引约 8 分钟，token 省约 40%
- SQLite 断点层保证中断重跑零浪费；行号校准自动执行
- 依赖 `.env` 的 API 配置与 requests；编排器仍负责拆段规划与验证汇总
- 两种执行器产出格式完全兼容，prompt/输出模板单源真相（`templates/`）
