# 命令速查与红旗（成人文学索引_v4.8.1 SKILL.md 深参）

> 归属：本文件内容自 `SKILL.md` 的「命令速查（本仓·定制侧）」与「常见错误 / 红旗」两小节整段挪入，一字未改；SKILL.md 原位置保留小节标题与指针。双胞胎对端 知识库转录_v5.4.2（内核主干）有同名文件，本仓（定制侧，含 style 子命令）命令以本文为准。

## 命令速查（本仓·定制侧，均已对照 scripts/ 代码核对）

统一调用前缀：`uv run --with requests --with python-dotenv python "<技能目录>/scripts/脚本.py"`；`orchestrate.py` 的 `--lib` 为全局参数。

| 目的 | 命令/子命令（关键参数） |
|---|---|
| 初始化/看状态 | `orchestrate.py --lib "<索引库>" init` / `status` |
| 清单批量导入/追更 | `orchestrate.py import-manifest --manifest <source-manifest.json> [--novel <覆盖书名>] [--author <覆盖作者>] [--split-only] [--force]` |
| 完整建库 | `orchestrate.py build --source <文件> --novel <书名> --author <作者> [--volume] [--chapters-per-seg 5] [--chars-per-seg 10000] [--workers 32] [--force] [--skip-existing]` |
| 验证门禁/续跑 | `orchestrate.py verify`；`orchestrate.py resume [--workers 32]` |
| 删书 | `orchestrate.py delete --novel <书名> --author <作者> [--yes]`（等价直调 `delete_novel.py` 同名参数） |
| 文风蒸馏（本仓独有） | `orchestrate.py style --novel <书名> --author <作者> [--style-skill <目录/.py/命令>] [--output-dir <目录>]`；直调 `style_distillation.py` 同名参数 |
| 语义索引（默认关） | `orchestrate.py semantic build [--model] [--force] [--batch-size 32]` / `semantic search "<查询>" [--top-k 5] [--threshold 0.5] [--json]` |
| 行号校准/引用体检 | `verify_and_fix_lines.py "<索引文件或目录>"... --lib <库> [--no-check] [--no-range]`；`check_line_refs.py --lib <库> [--detail]` |
| 重建小说导航 | `build_novel_index.py --novel "<书名-作者>"` 或 `--all --lib <库> [--force]` |
| 重命名/迁移旧库 | `rename_novel.py --old-novel --old-author --new-novel --new-author --lib [--yes]`；`migrate_library.py --from <旧> --to <新> [--copy] [--yes]` |

## 常见错误 / 红旗（本仓代码防御分支与测试实测，非臆造）

- **空库或目标书无章节索引就跑文风蒸馏**：`style_distillation.py` 返回 error，不再生成「抽样 0/0」占位成功卡；目标书未索引按降级路径答复（测试 `test_lightweight_style_refuses_empty_library`）。
- **书名含 `[` 等 glob 元字符**：`_common.py` 的 `norm_name` 强制转义，删除与风格索引匹配不误伤他书（测试 `test_delete_novel_bracket_name_does_not_touch_other_books`）。
- **把外部文风 skill 的报错原样回显**：`style_distillation.py` 会清洗 stderr 中的 traceback 与密钥，只保留规则名与截断尾部（测试 `test_external_skill_directory_crash_scrubs_traceback_and_secrets`）。
- **以为语义检索默认开着**：需 `INDEX_ENABLE_SEMANTIC=1` 或 `--build` 触发；无语义索引时 search 直接报错而非空结果（`semantic_index.py`；测试 `test_index_cli_default_disabled`、`test_search_cli_without_index_reports_error`）。
- **`OPENAI_API_KEY` 还是占位符 `sk-your-key-here` 就建库**：`build_segment_index.py` 直接拒绝（测试 `test_api_key_placeholder_rejected`）。
- **章节小标题逆序/行号越界的索引**：`build_segment_index.py` 的 `validate_index_output` 以「章节小节标题与段文件不匹配」拒收（测试 `test_review_fixes.py`）。
- **轻量风格卡越界抽样或当成品交付**：抽样受硬上限 `_MAX_LIGHTWEIGHT_SEGMENTS`（8~10 段）约束；脚本卡只是素材底稿，最终七维风格卡须由编排器按 `references/索引内容.md` 文风节重写（测试 `test_sample_segments_respects_hard_cap`）。
- **用户只说「建库/追更/体检/索引库」未指明语料就抢单**：这些词与「知识库转录」共用；本仓的判据是语料为小说/TXT网文、目的含笔法/蒸馏/仿写，若对方要的是长篇专著/资料/独立文档集与文件名+行号双引用问答应让给「知识库转录」，拿不准先问一句语料类型（测试 `tests/test_skill_discovery.py` 锁排除句）。
