# 成人文学索引

> 小说资料 · 作者风格 · **4.8.6** · [原始技能入口](../../成人文学索引_v4.8.6/SKILL.md)

为已有小说建立分段索引、章节导航和作者风格资料，按原文依据检索与分析。适合整理有使用权限的成人文学文本。

[使用流程](#使用流程) · [示例](#示例) · [边界与注意事项](#边界与注意事项) · [遇到问题](#遇到问题)

## 输入与交付

输入：TXT / Markdown 小说、书名、作者、独立索引库位置。

输出：原文段文件、章节/全书索引，以及按工序生成的风格卡。

## 开始之前

按 QUICKSTART.md 准备 Python 与 uv。索引服务使用 requests、python-dotenv，并需要配置模型接口；将 .env 留在本机。明确指定 --lib，不依赖当前目录猜测。

安装时完整复制 `成人文学索引_v4.8.6/`，由宿主按入口的 `name` 识别。宿主加载与脚本依赖是两件事；先看[通用安装说明](../getting-started.md)，再按下方原始文档准备。

## 使用流程

1. 先为一本小样本建立独立库，备份原始文件。
2. 按原文书名与作者建索引，检查切段及章节边界。
3. 抽查索引引用与原文一致，再生成风格卡或扩展其他书。
4. 检索后回读原文；改名、删除、重切段前备份库和关联风格卡。

### 命令入口

在技能根目录执行，使用已准备好的对应运行环境。`<…>` 是必须替换的占位符；下面的业务命令不是安装完成后的自动动作，也不代表本轮已执行真实业务。

```powershell
uv run --with requests --with python-dotenv python scripts/orchestrate.py --lib "<索引库绝对路径>" init
uv run --with requests --with python-dotenv python scripts/orchestrate.py --lib "<索引库绝对路径>" build --source "<源文件绝对路径>" --novel "书名" --author "作者"
```

## 配置与数据位置

| 配置 | 用途 |
| --- | --- |
| OPENAI_API_KEY | 索引接口凭据，仅留在本机 |
| SUMMARY_API_URL / SUMMARY_API_MODEL | 摘要与索引服务地址、模型 |
| INDEX_LIB_DIR / --lib | 明确指定索引库；命令中建议显式传 --lib |

主要资料在 `小说原文/`、`章节索引/`、`小说索引/`；相邻 `风格卡/` 下的书名-作者目录也要纳入备份。

## 边界与注意事项

- 仅处理有权使用的成年人虚构材料；索引与风格分析不能证明版权归属或授权范围。
- 没有收录的书不能假称已经检索；空书或资料不足不能编造风格卡。
- 风格卡可能存于索引库相邻的 风格卡/ 目录，备份不能只复制数据库。
- 摘要与索引构建可能调用外部模型；先检查服务、预算和隐私要求。

## 遇到问题

| 现象 | 建议处理 |
| --- | --- |
| 找不到文档或库 | 确认绝对路径，--lib 放在子命令前，书名与作者保持一致。 |
| 风格结论空泛 | 缩小到可回读段落，提供引用，资料不足就保留缺项。 |
| 重建后看不到旧内容 | 保留现场，检查 superseded 等历史段目录及备份，勿先清理。 |

恢复操作前保留原始输入、配置（脱敏）、日志和状态库；不要先删除现场。备份至少包含用户数据和工序状态，不能只备份技能文件。
